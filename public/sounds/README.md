# Optional recorded sounds

Drop audio files here and the game uses them instead of the synthesised versions.
Name them exactly as below (`.mp3` or `.ogg`). Any file that's missing falls back to the synth.

| File | What it should be | Notes |
|---|---|---|
| `engine.mp3` | Two-stroke auto engine, steady idle, **seamless loop** | Pitch and volume follow speed and throttle |
| `horn.mp3` | Auto horn, sustained, **loop** | Plays while H is held |
| `rain.mp3` | Steady monsoon rain on tin roofs, **loop** | |
| `crow.mp3` | House crow, 2–3 caws | |
| `koel.mp3` | Asian koel's rising "ku-oo" call | |
| `temple_bell.mp3` | Single temple bell strike | |
| `church_bell.mp3` | Church bell, 2–3 tolls | |
| `conductor_whistle.mp3` | Bus conductor's double pea-whistle | |
| `coin.mp3` | Coins / cash at the end of a trip | |
| `meter_tick.mp3` | Fare meter click | |
| `phone_buzz.mp3` | Phone vibrating on a hard surface | |

Good sources: Freesound.org (filter by **CC0** licence, or credit CC-BY authors), BBC Sound Effects (personal use only),
or record your own in Kerala. Check each clip's licence before you share or publish the game.
